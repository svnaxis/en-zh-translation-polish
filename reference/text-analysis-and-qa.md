# 文本分析 → 歸化尺度 → 準確性質檢（策略層）

基於功能文本理論（紐馬克 Peter Newmark 文本功能分類）與現代英譯中實務規範。
這一層決定「這篇文本該往中文靠攏多少」——是技巧庫 (techniques) 與病症指南 (symptoms) 的總開關：**先判定文本性質，再決定下手多狠**。

自由度只適用於表達方式。所有檔位均須保留事實、邏輯、限定、歸屬與語氣強度；訪談、新聞等混合文本按段落或資訊功能判斷，不因全文偏軟而放寬技術陳述的準確性。

---

## 小節 A — 翻譯前的文本分析：7 個維度 → 自由度

翻譯任何一篇文章前，都必須先釐清：這是一篇什麼樣的文章？面向什麼樣的讀者？
只有回答了這些問題，才能決定：到底該貼近原文結構，還是該大膽意譯與重組？

落筆前過一遍這 7 個判定維度，給文本一個「自由度」打分（0=必須緊貼原文，10=可大幅重構）：

1. **邏輯驅動 vs 情感驅動** (logic- vs emotion-driven)：經濟／法律／科技／哲學 = 邏輯驅動，貼原文邏輯；抒情／閒談／感嘆 = 情感驅動，可靈活，一原文可對多譯文。
2. **紐馬克三類** （A 表達 / B 資訊 / C 呼喚）：見小節 A2。
3. **正式 vs 非正式** （語域 register）：必須忠實傳達語域的潛台詞——原文莊重則譯文典雅，原文俚俗則譯文口語，原文辛辣則譯文辛辣。
4. **評價性強弱** (evaluative or not)：科技專利／法規契約 = 無評價→譯者少介入、重客觀準確；社論／文案／宣傳冊 = 強評價→可大幅調整結構、重感染力與流暢度。
5. **文化關聯高低** (culture-bound，引 Hatim & Mason 語篇理論)：文本與特定文化關係越薄弱，越不必大幅變動語言結構；文化根基越深厚，跨語言調整的幅度就越大。
6. **聚焦作者／情境／讀者** (focus on writer/situation/reader)。
7. **軟文本 vs 硬文本** （見小節 A3，最直觀的總判據）。

最後，文本特徵分析僅提供內在依據，實際翻譯還須權衡文本外因素——尤其是翻譯委託目的與目標受眾。

**判定結論 → 自由度 (1–10)**：商業合約≈2–3，大學教科書≈4–6，散文遊記≈7–8。自由度越低，重構手段越要克制。

### A2 — 紐馬克三類文本 → 工夫下在哪一層 (XYZ)

依據翻譯學者紐馬克 (Peter Newmark) 的文本功能模型：
- **A 表達功能** (expressive)：以作者為中心，如文學名著、個人演講。
- **B 資訊功能** (informative)：以客觀真實為中心，如科技報告、學術論文、說明書。
- **C 呼喚功能** (vocative)：以讀者反應為中心，旨在影響受眾情緒或行為，如廣告文案、募捐信。

紐馬克 XYZ 係數：Y=語言文字本身，X=客觀現實所指，Z=讀者腦中意象。

| 文本類 | 典型 | 工夫下在 | 策略 | 自由度 |
|---|---|---|---|---|
| **A 表達型** | 文學、經典著作、權威演講 | **Y （語言風格本身）** | 語義翻譯；短句譯短句，保留作者獨特風格與聲調 | 低至中 |
| **B 資訊型** | 科技、報告、法律合約 | **X （客觀事實／邏輯）** | 交際翻譯，嚴守事實與邏輯；術語統一固定 | 低 |
| **C 呼喚型** | 廣告、公關宣傳、行銷文案 | **Z （讀者感受效果）** | 靈活呈現原文修辭感染力，使中文讀者產生同等共鳴 | 高 |

> 英語與中文屬於不同語系，句法思維差異極大。在絕大多數英譯中實務中，**預設檔位是「交際翻譯／向中文習慣靠攏」**；唯有遇上 A 類具有獨特語言美感或歷史權威的表達型文本時，才調高對 Y（文字本身形式）的精準復刻。

### A3 — 文本質地軟硬（實務總開關）

余光中曾言「翻譯是戴著鐐銬跳舞」，文本質地正決定了鐐銬的輕重與舞步的空間：

- **「硬」文本**：邏輯骨架分明，容不得隨意打破結構，選詞必須極端精準，譯者個人風格應隱退其後，自由空間狹窄。
- **「軟」文本**：重在意境神韻與語言感染力，擺脫字面束縛的空間寬廣，譯者可盡情調用中文意合與音韻優勢。

| 硬文本（≈自由度 1–3）| 軟文本（≈自由度 7–9）|
|---|---|
| 詞義邊界清晰、解釋餘地小 | 詞義邊界彈性、詮釋空間大 |
| 個體風格弱、譯者不宜過度介入 | 個體風格強、譯者可靈活施展 |
| 句法邏輯嚴密、遵循規範語法 | 講求意象氛圍、容許修辭變通 |
| 文化負載低、講求功利實用 | 文化意涵濃、追求審美價值 |
| **政治／法律／經貿／科技／規範** | **詩歌／散文／專欄／演講／文案／行銷** |

> 實操法則：**先把文本定性為偏硬或偏軟，再決定修法清單裡哪些西化現象要嚴厲剔除、哪些可寬容保留**。在硬文本中，某些適度「西化」的嚴謹句式是為了精準度而付出的必要代價（異化可接受，底線是中文文意通順）；而在軟文本中，則應全力貫徹中文意合常態，追求道地與音律之美。

## 小節 B — 隱喻翻譯決策

從認知語言學視角切入：先區分**概念隱喻**（思維層面之映射）與**語言隱喻**（表層之具體字詞），再決定保留、揉合或捨棄。

許多看似奇特的隱喻背後，其概念隱喻往往植根於人類共通的感知經驗（空間、溫度、重力、旅程等）。這類共通隱喻在英中轉換時大多無障礙。

**決策路徑**:

1. **基本隱喻／圖像圖式隱喻**（基於大小、上下、冷熱、視覺、旅程等共通經驗）→ **直譯保留**，英中共有，生動自然。
   - 例：`LOVE IS A JOURNEY` → 「分道揚鑣」「走到十字路口」「步入死胡同」「原地踏步」。
2. **可直譯 ≠ 應直譯** → 須考量文本類型與語用對等：
   - 翻譯的核心是語用層面的功能對等。若直譯會引發歧義或文化誤解，應果斷換用中文慣用表達。
   - 例：婚姻 `gone off the track` 直譯「出軌」易與感情不忠混淆 → 改譯「脫離正軌」。
3. **文化專屬隱喻**（如特定歷史典故或宗教神話）→ 跨文化落差巨大，**揉合或捨棄**，轉為直接陳述。
   - 例：「新聞系臥虎藏龍」→ 捨棄字面隱喻，轉譯為 "the journalism department was full of highly talented people"（反之，英譯中遇文化專屬隱喻時亦需落地化解）。
4. **藉由隱喻圖像反推詞義**（深度理解工具）：當遇到語意抽象模糊的詞彙（如 tensions），還原其背後之概念隱喻意象（如兩股力量向相反方向拉扯）→ 尋求最貼切的中文譯法（「左右拉扯的膠著困境」）。

## 小節 C — 準確性質檢清單（潤色最後一道關）

專門排查「大體意思看似通順、但核心細節欠準」的譯文——這是潤色階段確保品質的防線。逐項核查：

- [ ] **雙向覆蓋與歸屬**：逐段重讀原文，核對每項論點、舉例、列舉與限定在譯文中的對應，再回查譯文陳述的原文依據。正文、圖表說明與不同受訪者之間嚴禁移花接木，標題與署名絕不憑空臆造。
- [ ] **未被逼到偏離卻擅自改結構**：思果告誡「能順著翻就順著翻」。在原文結構清晰、直譯完全符合道地中文時，切莫為了炫技而「捨近求遠」、節外生枝。
- [ ] **句型轉換造成重心／焦點偏移**：如 `The next four years…turned out…` 若將主詞「四年」降格為時間狀語，句意重心便從「歲月之變」偏向「人之境遇」；`A is B` 擅自反轉為 `B is A` 亦會擾亂論述焦點。硬文本中尤須審慎。
- [ ] **漏譯細節情態與虛詞**：`do know` 的強調語氣、`turned out` 的「結果竟是」、`ranks as` 的「位列」——在嚴肅論述中不得任意漏譯。
- [ ] **擅自添詞／過度詮釋**：原文未有的「良好」「全面」「深入」等形容詞切勿隨意增添；意譯不可淪為加油添醋。
- [ ] **搭配是否道地**：核查動賓、偏正搭配是否符合正體中文語感（例如避免出現「扎根於……身上」等畸形組合）。
- [ ] **指代與修飾層級**：理清 it/they 指涉對象，切勿將修飾語錯置為狀語，造成修飾關係混亂。
- [ ] **邏輯關係嚴謹性**：因果切勿譯為順接，讓步與條件切勿遺漏；必要條件（only if）不可誤改為充分條件，可能性（can）不可改為確定性或頻率判斷（「往往」）。
- [ ] **專名／術語／數字**：人名地名參照主流標準統一譯名（如臺灣慣用譯名：甘迺迪、歐巴馬、矽谷等），硬文本專業術語務必前後一致，數字逐一覆核無誤。
- [ ] **語域是否對齊**：典雅對典雅，口語對口語，俚俗對俚俗。
- [ ] **忠實與通順之衡平**：硬文本克制大幅改動；軟文本可靈活發揮修辭，但完整性、事實真偽、邏輯嚴密性與說話者語氣強度仍為不可逾越之底線。

> 關鍵紅線：表達方式可以千變萬化，原意傳達必須分毫不差。完成潤色後全面檢視最終譯文，查出問題立即回溯修正。
